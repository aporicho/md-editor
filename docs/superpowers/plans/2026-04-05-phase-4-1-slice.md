# Phase 4.1: Slice 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 `src/model/replace.rs` 的 `Slice` struct 及所有方法（`size`、`eq`、`to_string_repr`、`to_json`、`from_json`、`max_open`、`empty`、`insert_at`、`remove_between`）以及两个模块级私有函数（`remove_range`、`insert_into`），并在 `src/model/tests_slice.rs` 中提供完整覆盖测试。

**Architecture:**
- `Slice` 是简单值类型，包含 `content: Fragment`、`open_start: usize`、`open_end: usize` 三个字段。所有方法都返回新的 `Slice`（值语义，不可变）。
- `insert_at` / `remove_between` 是 @internal 方法，委托给模块级私有函数 `insert_into` / `remove_range`。这两个私有函数递归下降到 Fragment 的子树做插入/删除。
- `insert_into` 递归时需要调用 `Node::can_replace` 做结构性校验；`Node::can_replace` 已在 Phase 3.4-c 实现且**不需要 schema 参数**（通过 `self.node_type.content_match` 直接获取），所以本阶段 Slice 的公开 API **也不需要 schema 参数**。
- `from_json` 从 schema 反序列化；`empty()` 使用 `OnceLock<Slice>` 做静态常量（与 `Fragment::empty` 风格一致）。
- test-slice.ts 的测试主要测 `Node::slice()` 方法（依赖 ResolvedPos，Phase 4.7 才实现），本阶段的 `tests_slice.rs` 是**自写的单元测试**，直接构造 Slice / Fragment 进行覆盖，test-slice.ts 的移植推迟到 Phase 4.7。

**Tech Stack:** Rust, `std::sync::OnceLock`, `serde_json::Value`。

```rust
//! src/model/replace.rs
//!
//! Phase 4.1 — Slice struct + 模块级私有辅助函数（remove_range、insert_into）。
//! Phase 4.5+ 将在本文件续写 replace 算法。
#![allow(dead_code)] // TODO: Phase 4.7 replace 算法完整后移除

use std::sync::OnceLock;

use crate::model::fragment::Fragment;

static EMPTY_SLICE: OnceLock<Slice> = OnceLock::new();

/// A slice represents a piece cut out of a larger document. It
/// stores not only a fragment, but also the depth up to which nodes on
/// both side are 'open' (cut through).
#[derive(Clone)]
pub struct Slice {
    /// The slice's content.
    pub content: Fragment,
    /// The open depth at the start of the fragment.
    pub open_start: usize,
    /// The open depth at the end.
    pub open_end: usize,
}

impl Slice {
    /// Create a slice. When specifying a non-zero open depth, the caller
    /// must ensure that the fragment has nodes at least that deep on the
    /// appropriate side.
    pub fn new(content: Fragment, open_start: usize, open_end: usize) -> Self {
        Slice { content, open_start, open_end }
    }

    /// The empty slice.
    pub fn empty() -> Self {
        EMPTY_SLICE
            .get_or_init(|| Slice {
                content: Fragment::empty(),
                open_start: 0,
                open_end: 0,
            })
            .clone()
    }

    /// The size this slice would add when inserted into a document.
    pub fn size(&self) -> usize {
        self.content.size - self.open_start - self.open_end
    }
}
```

```rust
    /// Convert a slice to a JSON-serializable representation.
    /// Returns `None` when content is empty.
    pub fn to_json(&self) -> Option<Value> {
        if self.content.size == 0 {
            return None;
        }
        let mut obj = Map::new();
        // Fragment::to_json returns None for empty content, but here content.size > 0
        // so it must return Some; unwrap_or an empty array defensively.
        obj.insert(
            "content".to_string(),
            self.content.to_json().unwrap_or(Value::Array(vec![])),
        );
        if self.open_start > 0 {
            obj.insert("openStart".to_string(), Value::from(self.open_start as u64));
        }
        if self.open_end > 0 {
            obj.insert("openEnd".to_string(), Value::from(self.open_end as u64));
        }
        Some(Value::Object(obj))
    }
```

```rust
    /// Create a slice from a fragment by taking the maximum possible
    /// open value on both sides of the fragment.
    ///
    /// When `open_isolating` is `false`, isolating nodes (those whose spec
    /// has `isolating: true`) are treated as leaves and not descended into.
    pub fn max_open(fragment: Fragment, open_isolating: bool) -> Slice {
        let mut open_start = 0usize;
        let mut n = fragment.first_child();
        while let Some(node) = n {
            if node.is_leaf() { break; }
            if !open_isolating && node.node_type.spec.isolating { break; }
            open_start += 1;
            n = node.first_child();
        }
        let mut open_end = 0usize;
        let mut n = fragment.last_child();
        while let Some(node) = n {
            if node.is_leaf() { break; }
            if !open_isolating && node.node_type.spec.isolating { break; }
            open_end += 1;
            n = node.last_child();
        }
        Slice::new(fragment, open_start, open_end)
    }
```

```typescript
function removeRange(content: Fragment, from: number, to: number): Fragment {
  let {index, offset} = content.findIndex(from), child = content.maybeChild(index)
  let {index: indexTo, offset: offsetTo} = content.findIndex(to)
  if (offset == from || child!.isText) {
    if (offsetTo != to && !content.child(indexTo).isText) throw new RangeError("Removing non-flat range")
    return content.cut(0, from).append(content.cut(to))
  }
  if (index != indexTo) throw new RangeError("Removing non-flat range")
  return content.replaceChild(index, child!.copy(removeRange(child!.content, from - offset - 1, to - offset - 1)))
}
```

算法逻辑：
1. 找到 `from` 和 `to` 在 Fragment 里的位置（index/offset）。
2. 如果 `from` 正好落在某个子节点边界（`offset == from`）或是在文本节点内部（`child.isText`）：
   - 如果 `to` 也落在某个子节点边界（`offset_to == to`）或 `to` 所在的子节点也是文本节点 ⇒ 平凡删除：`cut(0..from) ++ cut(to..)`；
   - 否则（`to` 在一个非文本子节点内部但 `from` 在外）⇒ **非平凡区间**，报错 "Removing non-flat range"。
3. 否则（`from` 在一个非文本子节点内部）：
   - `to` 必须也在同一子节点内部（`index == index_to`），否则报错 "Removing non-flat range"；
   - 递归：对该子节点的 content 做 `removeRange(from - offset - 1, to - offset - 1)`，然后 `replaceChild(index, child.copy(new_content))`。

```rust
/// Internal: remove a flat range [from, to) from a fragment.
/// Returns `Err(RangeError)` when the range is not flat (spans multiple
/// non-text children at different depths).
fn remove_range(content: &Fragment, from: usize, to: usize) -> Result<Fragment, RangeError> {
    let (index, offset) = content.find_index(from)?;
    let (index_to, offset_to) = content.find_index(to)?;
    let child_is_text = content.maybe_child(index).map(|n| n.is_text()).unwrap_or(false);

    if offset == from || child_is_text {
        // 平凡删除路径
        if offset_to != to {
            // to 不在子节点边界 ⇒ 必须也是文本节点，否则非平凡
            let child_to_is_text = content.maybe_child(index_to)
                .map(|n| n.is_text())
                .unwrap_or(false);
            if !child_to_is_text {
                return Err(RangeError("Removing non-flat range".to_string()));
            }
        }
        return Ok(content.cut(0, Some(from)).append(&content.cut(to, None)));
    }

    // 非平凡路径：from 在某个非文本子节点内部
    if index != index_to {
        return Err(RangeError("Removing non-flat range".to_string()));
    }
    // 此时 maybe_child(index) 一定是 Some（因为 offset != from 且不在边界）
    let child = content.maybe_child(index)
        .expect("remove_range: child must exist when offset != from");
    let inner = remove_range(&child.content, from - offset - 1, to - offset - 1)?;
    Ok(content.replace_child(index, child.copy(Some(inner))))
}
```

```typescript
function insertInto(content: Fragment, dist: number, insert: Fragment, parent?: Node | null): Fragment | null {
  let {index, offset} = content.findIndex(dist), child = content.maybeChild(index)
  if (offset == dist || child!.isText) {
    if (parent && !parent.canReplace(index, index, insert)) return null
    return content.cut(0, dist).append(insert).append(content.cut(dist))
```

```rust
    parent: Option<&Node>,
) -> Option<Fragment> {
    let (index, offset) = content.find_index(dist).ok()?;
    let child_is_text = content.maybe_child(index).map(|n| n.is_text()).unwrap_or(false);

    if offset == dist || child_is_text {
        // 边界或文本节点内部 ⇒ 平凡插入
        if let Some(p) = parent
            && !p.can_replace(index, index, insert, 0, insert.child_count())
        {
            return None;
        }
        return Some(
            content.cut(0, Some(dist))
                .append(insert)
                .append(&content.cut(dist, None)),
        );
    }

    // dist 在一个非文本子节点内部 ⇒ 递归下降
    let child = content.maybe_child(index)?;
    let inner = insert_into(&child.content, dist - offset - 1, insert, Some(child))?;
    Some(content.replace_child(index, child.copy(Some(inner))))
}
```

```rust
            pos + self.open_start,
            fragment,
            None,
```

## 设计决策记录

### 决策 29：Slice 字段公开，与 Fragment/Node 风格一致

`Slice` 三个字段 `content`、`open_start`、`open_end` 均 `pub` 公开，与 `Fragment.size`、`Node.node_type`/`Node.content` 等现有风格一致。外部消费者（Phase 4.5+ 的 replace 算法）需要直接访问这些字段，无需 getter。

### 决策 30：Slice::insert_at / remove_between 不需要 schema 参数

`Node::can_replace` 在 Phase 3.4-c 实现时已确立"通过 `self.node_type.content_match` 直接获取 ContentMatch，不需 schema"的约定（Decision 27）。`insert_into` 递归调用 `parent.can_replace(...)` 顺理成章不传 schema，因此 `Slice::insert_at` 的公开 API 也保持简洁（只接受 pos + fragment）。

### 决策 31：test-slice.ts 移植推迟到 Phase 4.7

test-slice.ts 的 20+ 个测试全部测 `Node::slice()` 方法，该方法依赖 `ResolvedPos`（Phase 4.2–4.4）才能实现。Phase 4.1 的 `tests_slice.rs` 是**自写的单元测试**，直接构造 `Slice`/`Fragment` 覆盖每个公开方法与错误路径。完整对齐 test-slice.ts 将在 Phase 4.7 `tests_replace.rs` 里顺带完成。
